# Family Board

거실 태블릿에 하루 종일 켜 두는 가족 대시보드입니다. 엄마·아빠는 폰 브라우저로 같은 주소에 들어와서 보고 고칩니다.

- 아이별 **매일 할 일** 목록: 카드에서 손가락으로 바로 체크, 끝낸 일은 아래로, 길면 카드 안에서 스크롤. 매일 자정(태블릿 시계 기준)에 초기화
- 💰 **보상**: 그날 할 일을 모두 끝내면 아이 적립금에 $1 (같은 날 체크를 풀면 다시 빠짐). 아이 카드에 적립금과 할 일 목록 표시, 부모가 ⚙️ 설정에서 적립금 수정
- 🏫 **학원·일정**: 학원마다 요일·시간·메모(교실 등)·준비물·다니는 기간을 등록. 아이 카드에 오늘(저녁 6시 이후엔 내일) 일정과 준비물 표시. 학원 15분 전 태블릿 알람. 달력에서 휴강·보강 표시
- 🗓 **한 달 달력**: 학원·가족 일정·외부 달력을 한눈에. 외부 달력은 비공개 iCal 주소를 ⚙️ 설정에만 입력 (주소는 서버에만 저장, 화면·로그에 안 나옴, 30분마다 동기화). 일정 제목을 `민준: 피아노`처럼 아이 이름으로 시작하면 그 아이 카드에 나옴
- 🌤 **날씨**: 지금·최저/최고·시간별, 미세먼지, 옷차림 한마디. Open-Meteo(키 없음)가 막히면 MET Norway로 자동 전환. 위치는 ⚙️ 설정에서
- 📱 **기기 추가**: ⚙️ 설정에서 등록 링크를 만들면 새 기기는 PIN 없이 등록 (15분 안에 한 번만)
- 📌 **해야 할 일 게시판**: 부모가 아이에게 쪽지를 붙이면 받는 아이가 각자 "했어요"를 누를 때까지 남음.
  시작일~마감일, 매일 알람 시각(아직 안 한 아이만 태블릿에서 울림), 끝낸 쪽지는 기록으로 30일 보관
- 📮 **가족 우체통**: 태블릿에서 아이가 자기를 고르고 받는 사람(여러 명/모두)에게 자주 쓰는 문구나 직접 쓴 쪽지를 보냄.
  부모 폰은 빠른 답장, 읽음 표시, 안 읽은 쪽지 수 배지, **부모 폰 푸시 알림**
- 다가오는 일정 (아이별·가족 칸으로 나눠 보기, 칸마다 스크롤), 가족 메모
- 아이마다 이름·이모지·색 설정
- 영어/한국어 화면 (기본 영어, 기기마다 🌐 버튼으로 전환)
- Node.js 내장 모듈만 사용 — `npm install` 필요 없음

## 권한

| | 등록 안 된 기기 | 가족 화면 기기 | 부모 기기 |
|---|:-:|:-:|:-:|
| 데이터 보기 | ✗ | ✓ | ✓ |
| 할 일 체크, 일정 추가 | ✗ | ✓ | ✓ |
| 우체통 쪽지 보내기 | ✗ | ✓ (아이 이름으로) | ✓ (엄마/아빠 이름으로) |
| 게시판 쪽지 "했어요" 체크 | ✗ | ✓ | ✓ |
| 게시판 쪽지 붙이기 | ✗ | ✗ | ✓ |
| 설정(아이·할 일 추가·수정·삭제, 적립금 수정, 기기 관리, PIN 변경), 삭제 | ✗ | ✗ | ✓ |

- 모든 기기는 **부모 PIN**을 입력하거나, 부모 기기에서 만든 1회용 링크로 등록해야 데이터에 접근할 수 있습니다. 부모 기기용 링크는 PIN을 한 번 더 확인합니다.
- 권한은 모두 **서버**에서 확인합니다. 화면을 고치거나 요청을 흉내 내도 태블릿·등록 안 된 기기는 부모 기능을 쓸 수 없습니다.
- 처음 설정할 때 PIN을 직접 정합니다(4~8자리, 0000·1234 같은 쉬운 숫자는 거부). PIN은 scrypt 해시로만 저장되고 화면·로그에 남지 않습니다.
- PIN을 한 곳(IP)에서 5번, 또는 모든 곳을 합쳐 20번 틀리면 5분 동안 막힙니다. IP 헤더를 흉내 내도 피할 수 없습니다.
- 잃어버린 기기는 부모 기기의 ⚙️ Settings에서 등록을 해제하세요.

## PC에서 실행하기

Node.js 18 이상이 필요합니다.

```bash
node server.js
```

터미널에 나오는 주소로 접속합니다.

- PC: `http://localhost:3000`
- 같은 와이파이의 태블릿·폰: `http://192.168.x.x:3000` (터미널에 표시됨)

로컬에서는 데이터가 프로젝트 폴더의 `data.json`에 저장됩니다. (`.gitignore`에 포함되어 커밋되지 않습니다.)

| 환경변수 | 기본값 | 설명 |
|---|---|---|
| `PORT` | `3000` | 서버 포트 |
| `DATA_FILE` | `./data.json` | 로컬 데이터 파일 위치 |

### 처음 쓸 때

1. 처음 접속한 기기에서 **부모 PIN**(숫자 4~8자리)을 만듭니다. 이 기기는 부모 기기가 됩니다.
2. 태블릿에서 같은 주소로 접속 → PIN 입력 → **Family screen**으로 등록합니다.
3. 엄마·아빠 폰도 PIN 입력 → **Parent device**로 등록합니다.
4. 부모 기기의 ⚙️ Settings에서 아이 이름·이모지·색과 매일 할 일(최대 20개)을 정합니다.
5. 부모 폰 화면 위쪽에서 **이 폰이 누구 건지(엄마/아빠)** 고릅니다. 우체통과 게시판은 이걸 정해야 쓸 수 있습니다.
6. 📮 Mailbox → **🔔 Turn on notifications** 를 누르고 알림을 허용하면, 쪽지가 올 때 폰으로 알림이 옵니다.
   - 알림은 HTTPS 주소(Vercel 배포 주소)에서만 동작합니다. `http://192.168...` 로컬 주소에서는 안 됩니다.
   - 아이폰: Safari에서 공유 → **홈 화면에 추가** 한 뒤, 홈 화면 아이콘으로 열어서 알림을 켜야 합니다 (iOS 16.4 이상).

PIN은 ⚙️ Settings 맨 아래에서 바꿀 수 있습니다 (현재 PIN 필요). 이미 등록된 기기는 그대로 쓸 수 있습니다.

### 테스트

```bash
node test.js
```

- `test.js`: 기능·권한·동시 저장 점검
- `node security-check.js`: 가짜 가족 데이터로 등록 안 된 기기·태블릿·흉내 낸 요청이 막히는지 22가지 점검

둘 다 **다른 포트와 임시 데이터 파일**로 서버를 따로 켜서 시험하고, Firebase 설정이 있어도 무시합니다. 실제 가족 데이터는 건드리지 않습니다.

### 데이터 구조를 바꿀 때

1. `api/index.js`의 `SCHEMA`를 올리고 `norm()`에 변환을 넣습니다.
2. 태블릿 데이터 사본으로 미리 해 봅니다. Firebase 콘솔 → Realtime Database → ⋮ → **JSON 내보내기**로 받은 파일을:
   ```bash
   node migrate-check.js 내보낸파일.json
   ```
   기존 기록이 하나라도 바뀌거나 사라지면 ❌로 알려 줍니다. 파일은 읽기만 합니다.
3. 배포하면 서버가 예전 구조 데이터를 처음 읽을 때 **원본을 그대로 백업**(Firebase `familyboard_backup_v1-날짜` / `data.json.backup-…`)한 다음에 변환본을 저장합니다.

## Vercel에 배포하기 (무료)

Vercel 서버는 파일을 계속 저장할 수 없으므로 데이터는 **Firebase Realtime Database**에 저장합니다.
무료 Spark 요금제로 충분하며 카드 등록이 필요 없습니다. (요청 횟수 제한이 없고 저장 용량·다운로드 양만 제한됩니다.)

### 1. Firebase 데이터베이스 만들기

1. [console.firebase.google.com](https://console.firebase.google.com) → **프로젝트 추가** (Google Analytics는 꺼도 됩니다).
2. 왼쪽 메뉴 **빌드 → Realtime Database → 데이터베이스 만들기**.
   - 위치: 가까운 곳 (예: `asia-southeast1` 싱가포르)
   - 보안 규칙: **잠금 모드**로 시작 — 외부에서 직접 접근은 모두 막히고, 서버만 서비스 계정으로 접근합니다.
3. 만들어진 데이터베이스 주소를 복사합니다. 예: `https://my-family-default-rtdb.asia-southeast1.firebasedatabase.app`
4. ⚙️ **프로젝트 설정 → 서비스 계정 → 새 비공개 키 생성** → JSON 파일이 다운로드됩니다.
   이 파일은 비밀번호와 같으니 **절대 GitHub에 올리지 마세요.**

### 2. Vercel 프로젝트 만들기

1. vercel.com → **Add New → Project** → 이 GitHub 저장소를 가져옵니다.
   Framework Preset은 **Other**, 빌드 설정은 비워 둡니다.
2. **Settings → Environment Variables** 에 두 개를 추가합니다.

   | 이름 | 값 |
   |---|---|
   | `FIREBASE_DB_URL` | 1-3에서 복사한 데이터베이스 주소 |
   | `FIREBASE_SERVICE_ACCOUNT` | 1-4에서 받은 JSON 파일 **내용 전체**를 그대로 붙여넣기 |

3. 환경변수는 다음 배포부터 적용되므로 **Deployments → Redeploy** 를 누릅니다.
4. 배포 주소에 바로 접속해서 **부모 PIN부터 만드세요.** 가장 먼저 PIN을 만든 사람이 부모가 됩니다.

환경변수 없이 배포하면 화면에 "Firebase is not connected" 오류가 나옵니다.

| 선택 환경변수 | 설명 |
|---|---|
| `BOARD_KEY` | Firebase 안의 저장 위치 이름 (기본 `familyboard`). 같은 데이터베이스를 여러 보드가 쓸 때만 바꾸세요 |

### 로컬에서 실제 Firebase로 확인하기

```bash
export FIREBASE_DB_URL=https://....firebasedatabase.app
export FIREBASE_SERVICE_ACCOUNT="$(cat 다운로드한-키.json)"
node server.js   # 실제 데이터로 실행
node test.js     # 테스트 위치에서 점검 후 정리
```

## 알아둘 점

- **화면 갱신:** 다른 기기에서 바꾼 내용은 최대 10초 안에 보입니다. 간격은 `public/index.html`의 `POLL_MS`로 조절합니다.
  화면은 10초마다 작은 버전 값만 확인하고, 바뀌었을 때만 전체 데이터를 받습니다.
- **게시판 알람:** 태블릿 화면이 켜져 있어야 울립니다(서버 예약 작업은 Vercel 무료 요금제에서 쓸 수 없음).
  브라우저는 한 번 화면을 터치한 뒤에만 소리를 낼 수 있으니, 태블릿을 켠 뒤 아무 곳이나 한 번 눌러 두세요.
  알람은 부모 폰으로는 가지 않습니다. 우체통 쪽지만 부모 폰으로 푸시 알림이 갑니다.
- **자동 정리:** 우체통 쪽지는 30일·최근 60개까지, 끝낸 게시판 쪽지 기록은 30일·최근 50개까지 남습니다.
- **무료 한도:** 평소에는 버전 값만 확인하므로 Firebase 다운로드 양이 아주 적습니다. Spark 요금제 한도는 [Firebase 요금 페이지](https://firebase.google.com/pricing)에서 확인하세요. 한도를 넘어도 요금이 청구되지 않고, 그날은 접속이 막혔다가 다음 날 풀립니다.
- **태블릿 화면 꺼짐:** 안드로이드 설정에서 화면 자동 꺼짐을 끄거나, 개발자 옵션의 "충전 중 화면 켜짐 유지"를 켜세요. (HTTPS인 Vercel 주소에서는 브라우저가 화면 켜짐 유지도 시도합니다.)
- **동시 수정:** 두 기기가 동시에 고쳐도 한쪽 변경이 사라지지 않도록 저장 시 버전(ETag)을 확인하고 재시도합니다.

```
api/index.js       API 전체 (Vercel 함수 겸 로컬 서버용 핸들러), 저장소(Firebase / data.json)
public/index.html  화면 (HTML/CSS/JS 한 파일, 영어/한국어 문구 포함)
public/sw.js       부모 폰 푸시 알림 처리
public/manifest.json  홈 화면에 추가(아이폰 알림용)
server.js          로컬 실행용 서버
test.js            기능·권한·동시 저장 점검
security-check.js  가짜 데이터로 권한 점검
migrate-check.js   데이터 구조 변환 미리 해 보기 (사본만 읽음)
```
